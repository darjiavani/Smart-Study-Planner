# 📚 Smart Study Planner – HTML CSS JavaScript

A fully responsive and interactive **Smart Study Planner** designed to help students manage time, organize subjects, and boost productivity. Built using **HTML, CSS, and JavaScript**, this tool includes a weekly calendar, Pomodoro timer, AI-style study suggestions, and progress tracking.

---

## 🚀 Features

### ✅ Add & Manage Subjects  
Easily add subjects you want to study and update your weekly planning.

### 🗓 Weekly Calendar  
An interactive calendar to assign subjects to each day.

### ⏳ Pomodoro Timer  
25–5–15 cycle timer for maximum productivity.

### 🤖 AI Study Suggestions  
Generates smart study recommendations based on your subjects.  
*(No API used — fully built using your own JavaScript logic.)*

### 💾 Save & Load  
All your data is saved using **LocalStorage**.

### 📊 Progress Tracker  
View total study hours and track improvement.

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**
- **LocalStorage**
